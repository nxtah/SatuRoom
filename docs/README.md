# Dokumentasi SatuRoom

## Urutan membaca

1. `../AGENTS.md` — aturan yang mengikat untuk agen, keamanan, arsitektur, pola kode, dan cara tes.
2. `../RENCANA_FLOW.md` — keputusan pemilik dan progres fitur yang sudah benar-benar selesai.
3. `ARAH_PENGEMBANGAN_BOLA.md` — roadmap produk akademi sepak bola berikutnya.
4. `RISET_PERAN_DAN_FITUR.md` — desk research peran dan kebutuhan akademi.

## Starter Pack asli

Folder lokal `../SatuRoom packs/` adalah dokumen brief dan prompt asli pemilik. Folder itu tetap
disimpan sebagai referensi, tidak menjadi sumber instruksi utama karena sebagian isinya adalah audit
historis dan asumsi proyek lama yang sudah digantikan oleh `AGENTS.md` dan `RENCANA_FLOW.md`.

Jangan menyalin dokumen server, credential, atau konfigurasi lokal ke folder ini. Detail server tetap
hanya boleh berada di `.local/` yang tidak masuk Git.

## Status keputusan

- **Final**: sudah diputuskan pemilik dan harus diikuti.
- **Rencana**: urutan pengembangan yang boleh berubah saat ada kebutuhan akademi nyata.
- **Perlu keputusan**: jangan diimplementasikan sebagai fakta sebelum pemilik memilihnya.
