# Definition of Done

## Product: stated user problem, acceptance criteria, approved scope, clear language.
## UX: obvious primary action; coherent hierarchy; no dead controls/fake data/accidental blank sections; relevant states handled; accessibility/responsiveness checked; design system reused.
## Engineering: server validation and authorization; business scope on all relevant reads/writes; migrations included; tests added and actually run; no secret or unnecessary personal data leaks; intentional errors; no unrelated large refactor.
## Delivery: docs and decisions updated; local setup works or limitations stated; exact verification results reported; risks/follow-up listed; production/destructive actions approved explicitly.
