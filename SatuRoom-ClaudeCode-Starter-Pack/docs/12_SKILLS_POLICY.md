# Claude Code Skills and Plugin Policy

Skills provide reusable procedures, not a substitute for tests/review/security. Audit current version and existing skills first. Prefer official, reputable, maintained sources. Inspect contents/permissions before installation. Avoid overlapping skill overload. Never blindly run untrusted scripts. Skills must not deploy, access secrets, or make destructive changes without approval. Record name/source/version/purpose/risk/status. Never claim installation succeeded without verification.

## Useful categories
UX research; design system/frontend; accessibility; backend/API; database/migrations; security/authorization; browser/e2e testing; release/deployment.

## Starting point to evaluate
Anthropic's official docs and public `anthropics/skills` repository. Verify current docs and repo state. Project-local skills in `.claude/skills/` are included in this pack and should be reviewed/committed.
