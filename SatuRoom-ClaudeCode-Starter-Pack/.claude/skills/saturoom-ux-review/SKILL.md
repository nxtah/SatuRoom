name: saturoom-ux-review
description: Review SatuRoom web UX, navigation, onboarding, page hierarchy, and interface states. Use for screen design or UX reviews.
---

Read `CLAUDE.md` and UX principles. Identify role, context, goal, primary action, and hierarchy. Check whether the user knows where they are, what they can do, and what happens next. Prefer plain Indonesian and progressive disclosure. Review loading/empty/error/success/validation/denied/narrow states, keyboard, labels, focus, contrast, semantics, and status not conveyed by color alone. Flag clutter, generic dashboard filler, dead controls, placeholder sections, accidental blank space, and jargon. Report severity, evidence, fixes. Never claim research without evidence.
