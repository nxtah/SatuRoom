# SatuRoom Rasa (F&B)

Produk F&B terpisah dari `bola/`. Port lokal: `3300`. Tema: hangat, cepat dibaca saat operasional, warna dapur/plate/saffron/basil — bukan tema lapangan sepak bola.

Ruang domain berikutnya: menu, kategori, pesanan, dapur, meja, pembayaran pencatatan, stok, dan laporan. Schema PostgreSQL nanti berada di `fnb/migrations/`; jangan memakai schema `bola`.

Rencana lengkap: `../docs/RENCANA_FNB.md`.
